## ทำไมต้องขาย CPU มือสองกับ Winner IT (กาฬสินธุ์)

### 1) ประเมินราคาโดยอิงสภาพจริง ไม่ใช่เดาเหมารวม

CPU แต่ละรุ่นมีมูลค่าแตกต่างกันตาม “สายการใช้งาน” และ “อายุการใช้งาน” บางตัวถึงจะเป็นรุ่นใกล้กัน แต่สภาพขา (contact) ความสะอาดของผิวชิป หรือรอยใช้งานที่บ่งบอกการใช้งานหนัก-เบา ส่งผลต่อความเสี่ยงในการใช้งานต่อ ดังนั้น Winner IT จึงให้ความสำคัญกับข้อมูลที่คุณส่งมาและการตรวจรายละเอียดที่เกี่ยวข้องกับการทำงานจริง

### 2) ชัดเจนเรื่องความคุ้มค่า เหมาะทั้งเครื่องบ้านและงานออฟฟิศ

ไม่ว่าคุณจะอัปเกรดเครื่องเดสก์ท็อป หรือเก็บอะไหล่สำรองไว้ CPU มือสองอาจกลายเป็นต้นทุนที่ดีให้คนที่กำลังประกอบเครื่องในงบจำกัด Winner IT ช่วยคุณ “หามูลค่าที่เหมาะสม” ตามสภาพจริง และให้คุณรู้ว่าเราคิดราคาอย่างไร เพื่อให้ตัดสินใจได้สบายใจ

*   **เน้นความโปร่งใส** ให้คุณเห็นหลักเกณฑ์
*   **ลดความเสี่ยง** ด้วยการตรวจสภาพก่อนสรุปราคา
*   **บริการเป็นระบบ** ตั้งแต่ติดต่อจนส่งมอบ

## หลักเกณฑ์ประเมินราคาของ Winner IT แบบโปร่งใส

### 1) รุ่น/สเปก (Generation, Socket, ซีรีส์การใช้งาน)

CPU ไม่ได้มีราคาเท่ากันทุกตัว—even อยู่ตระกูลเดียวกัน สเปกและรุ่นย่อยมีผลต่อการใช้งานในตลาดจริง โดย Winner IT จะพิจารณาอย่างน้อย 3 ส่วนหลัก ได้แก่ รุ่น (เช่น i5/i7/Ryzen ซีรีส์ที่เกี่ยวข้อง), Socket (เพื่อดูความเข้ากันได้), และระดับความนิยม/ความต้องการในการนำไปประกอบเครื่อง

### 2) สภาพภายนอกและโอกาสการใช้งานต่อ

สิ่งที่มีผลจริง เช่น ความสะอาดของผิวชิป (die area), สภาพขา (pins) หรือซ็อกเก็ตที่เกี่ยวข้อง, รอยไหม้/คราบออกไซด์, และสภาพทั่วไปที่สะท้อนการดูแลระหว่างใช้งาน หาก CPU เคยใช้งานหนักหรืออาจมีความเสี่ยงด้านความร้อน ก็มีผลต่อการประเมินราคา Winner IT จะอธิบายให้คุณฟังว่าจุดไหนทำให้ราคาขยับ และคุณควรเตรียมข้อมูลเพิ่มอะไร

### 3) ประวัติการใช้งานเบื้องต้น (อัปเกรด / เครื่องเดิมเสีย / เคยเปิดติดใช้งานได้)

ข้อมูลจากคุณมีค่ามาก เช่น CPU เคยใช้งานอยู่จริงก่อนถอดหรือไม่ ถอดด้วยเหตุผล “อัปเกรด” หรือ “ปัญหาเครื่องมีอาการ” หากคุณบอกสาเหตุถูกต้อง เราจะประเมินความน่าเชื่อถือของการใช้งานต่อได้แม่นขึ้น และช่วยให้ได้ราคาที่ตรงกับสภาพจริง

**Checklist ก่อนส่งข้อมูลให้ Winner IT (ช่วยให้ประเมินได้ไวและแม่น)**

1.  จดชื่อรุ่น CPU ให้ถูกต้อง (ตัวอักษร/ตัวเลขบนกล่องหรือบนตัว CPU ถ้ายังมี)
2.  ถ่ายรูปด้านบน/ด้านล่างให้เห็นรายละเอียดขาและผิวชิป
3.  แจ้งสาเหตุที่ขาย เช่น อัปเกรด, เปลี่ยนเครื่อง, หรือมีอาการใช้งานผิดปกติ
4.  ถ้ามีหมายเลข S/N หรือสติ๊กเกอร์บนกล่อง ให้ส่งรูปประกอบ

เป้าหมายของเราไม่ใช่ “ลดราคาเพราะไม่รู้” แต่คือ “ประเมินให้รู้” ด้วยข้อมูลที่ครบและตรวจตามขั้นตอน

## ตรวจสภาพ CPU อย่างไรให้ได้ราคาดีและลดความเสี่ยง

### 1) จุดที่ทำให้ราคาลดลง (และควรตรวจก่อนขาย)

บางปัญหาเห็นไม่ชัดเมื่อถ่ายรูปแบบระยะไกล Winner IT จึงอยากให้คุณตรวจเองเบื้องต้นก่อนส่ง เช่น

*   **ขาสกปรก/มีคราบเหนียว** อาจกระทบการสัมผัส
*   **มีรอยงอ/หัก** บริเวณขา หรือขอบซ็อกเก็ต
*   **คราบออกไซด์** ที่เกิดจากความชื้น

ถ้าคุณพบจุดเหล่านี้ การเตรียมคำอธิบายจากคุณจะช่วยให้เราประเมินได้เร็วขึ้น และลดความเข้าใจผิด

### 2) วิธีถ่ายรูปให้เห็น “จุดสำคัญ” (เพื่อคุยราคาได้ตรง)

รูปที่ดีทำให้ประเมินได้ไวและลดรอบการถามกลับ แนะนำให้ถ่ายแบบนี้

*   ถ่ายให้เห็น**รุ่น CPU** และรหัสตัวอักษรชัดเจน
*   ถ่าย**ด้านขา** ใกล้พอให้เห็นความสมบูรณ์
*   ถ่าย**ผิวชิป** (บริเวณกลาง) เพื่อดูคราบ/รอย

หากรูปไม่ชัดเจน เราจะขอข้อมูลเพิ่มเพื่อความยุติธรรมกับทั้งสองฝ่าย

### 3) การเก็บรักษา CPU ระหว่างรอส่งมอบ

CPU เป็นชิ้นส่วนที่ต้องระวังเรื่องการกระแทกและความชื้น คุณควรใส่ในซองกันกระแทกหรือภาชนะที่มีฟองน้ำรอง และหลีกเลี่ยงการวางในที่ร้อนจัดหรือชื้น หากมีความเสี่ยงว่าขาอาจสัมผัสกับฝุ่น ให้เก็บแบบปิดสนิท

**คำแนะนำที่ทำได้ทันที**

*   ไม่ควรเช็ดขาด้วยของเหลวแบบไม่แน่ใจชนิด เพราะอาจทิ้งคราบ
*   ถอดออกจากเครื่องแล้วควรแพ็กทันที เพื่อลดโอกาสขาเสียรูป
*   หากมีซิลิโคน/คราบเก่า ให้แจ้งตามจริง ไม่ต้องพยายามแต่งให้เหมือนใหม่

## FAQ รับซื้อ CPU มือสองที่กาฬสินธุ์

### 1) CPU รุ่นไหนขายได้บ้าง?

ส่วนใหญ่ CPU ที่ยังอยู่ในสภาพดีและเป็นรุ่นที่ตลาดใช้งานต่อได้จะได้รับการประเมินราคา โดยสิ่งที่ช่วยให้ประเมินแม่นขึ้นคือ “รุ่น/สเปก” และรูปด้านขาและผิวชิป

### 2) ถ้า CPU ใช้งานไม่ได้/เปิดไม่ติด ยังขายได้ไหม?

มีโอกาสประเมินได้เช่นกัน แต่ราคาจะขึ้นกับสภาพและข้อมูลที่คุณแจ้ง เช่น เคยเปิดติดหรือไม่ อาการก่อนถอดเป็นอย่างไร และสภาพจริงที่ตรวจพบ Winner IT จะประเมินแบบโปร่งใสตามความเสี่ยง

### 3) ต้องมีของครบชุดไหม เช่น กล่องหรือซิลิโคนเดิม?

ถ้ามีกล่องหรือเอกสารประกอบจะช่วยยืนยันข้อมูลรุ่นได้เร็วขึ้น ส่วนเรื่องซิลิโคนเดิมให้แจ้งตามสภาพจริง ไม่ต้องพยายามทำใหม่ เราจะให้ความสำคัญกับ “ความสมบูรณ์ของตัว CPU” มากกว่า

### 4) ทำไมบางครั้งได้ราคาต่างจากที่คิด?

เพราะราคาขึ้นกับสภาพจริงและรายละเอียดที่มีผลต่อการใช้งานต่อ เช่น สภาพขา ความสะอาดของผิวชิป และสาเหตุการถอดจากเครื่อง หากคุณให้ข้อมูลครบและรูปชัดเจน ราคาจะใกล้เคียงช่วงที่ประเมินมากที่สุด

### 5) เตรียมรูปแบบไหนถึงจะคุยราคาได้ไว?

แนะนำถ่ายให้เห็น 1) รุ่น/รหัสบนตัวสินค้า 2) ด้านขาใกล้พอให้เห็นความสมบูรณ์ 3) ผิวชิปตรงกลาง ถ้าคุณส่งรูปครบตั้งแต่แรก การประเมินเบื้องต้นจะรวดเร็วขึ้น

### 6) มีเช็คลิสต์อะไรที่ควรตรวจก่อนส่ง CPU?

ให้ลองตรวจความสมบูรณ์ของขา, ดูคราบหรือความผิดปกติบนผิวชิป, และจัดเก็บให้ไม่กระแทกระหว่างรอส่งมอบ หากพบความผิดปกติให้แจ้งตามจริง

### 7) การประเมินราคามีความโปร่งใสอย่างไร?

Winner IT จะสรุปราคาโดยอิงข้อมูลรุ่น/สเปก ประกอบกับสภาพที่ตรวจพบ พร้อมอธิบายเหตุผลในระดับที่คุณเข้าใจได้ เพื่อให้คุณไม่รู้สึกว่าเป็นการ “ตั้งราคาแบบไม่ตรวจสอบ”

### 8) ถ้าอยู่กาฬสินธุ์ ต้องส่งสินค้ายังไง?

คุณสามารถติดต่อเพื่อให้ทีมงานแนะนำวิธีส่งมอบที่เหมาะสม โดยคำนึงถึงความปลอดภัยของสินค้าและความสะดวกของคุณ

### 9) ขายแล้วต้องกังวลเรื่องข้อมูลในเครื่องไหม?

CPU เป็นชิ้นส่วนฮาร์ดแวร์ ไม่มีข้อมูลส่วนบุคคลเหมือนอุปกรณ์จัดเก็บ (เช่น SSD/HDD) อย่างไรก็ตาม หากคุณนำ CPU ออกมาจากเครื่อง ควรดูแลให้ปิดเคส/ถอดอย่างถูกวิธี และแพ็กสินค้าให้เรียบร้อย
