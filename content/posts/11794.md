## ทำไมเครื่องพิมพ์รูปมือสองถึงประเมินราคาแบบ “เฉพาะทาง”

### 1) สภาพหัวพิมพ์และคุณภาพงานพิมพ์ ส่งผลต่อมูลค่ามากกว่าที่คิด

เครื่องพิมพ์รูปไม่ได้ดูแค่ “เปิดติดหรือไม่” เท่านั้น แต่สิ่งที่กำหนดราคาจริงคือความสามารถในการพิมพ์ออกมาได้คุณภาพตามสภาพหัวพิมพ์ (Print head) และระบบอัด/ฉีดหมึกในเครื่องนั้นๆ หากหัวพิมพ์เสื่อมหรืออุดตัน อาจทำให้สีเพี้ยน เส้นแตก หรือพิมพ์ไม่สม่ำเสมอ ซึ่งจะกระทบทั้งความน่าใช้งานและต้นทุนการซ่อม/บำรุงรักษา

### 2) อุปกรณ์ประกอบและการดูแลรักษา ทำให้รุ่นเดียวกัน “ราคาต่างกัน”

เครื่องพิมพ์รูปบางรุ่นให้คุณภาพแตกต่างตามสภาพการใช้งาน เช่น เคยใช้งานหนักหรือเก็บไว้นาน (หมึกแห้ง/คาร์ทริดจ์เสื่อม) รวมถึงมีอุปกรณ์ครบหรือไม่ เช่น สายไฟ สาย USB อะแดปเตอร์ กระดาษ/ชุดอุปกรณ์เสริมที่เกี่ยวข้อง การประเมินจึงต้องละเอียดเพื่อความยุติธรรมกับทั้งผู้ขายและผู้ซื้อ

## เช็กลิสต์ก่อนขาย: สภาพเครื่อง, หัวพิมพ์, การพิมพ์จริง

### 1) ตรวจอาการพื้นฐาน: เปิดเครื่องได้จริงไหม มีเสียงผิดปกติหรือไม่

คุณสามารถเช็คเบื้องต้นได้ใน 10-15 นาที ช่วยให้คุณเล่าให้ร้านได้ตรงและช่วยประเมินราคาเร็วขึ้น

*   เปิดเครื่องแล้วระบบเริ่มทำงานปกติหรือไม่
*   มีเสียงขัด/สะดุดเวลาเครื่องดึงกระดาษไหม
*   มีไฟเตือน (error) หรือสัญญาณเตือนหมึก/หัวพิมพ์หรือไม่
*   เครื่องพิมพ์ออกมาได้ต่อเนื่องหรือหยุดกลางคัน

### 2) ทำ “ทดสอบการพิมพ์” ก่อนนำมาเสนอขาย จะได้ข้อมูลชัดเจน

ถ้าเครื่องยังใช้งานได้ ลองสั่งพิมพ์ทดสอบ (ตามเมนูของรุ่นนั้นๆ) เช่นหน้า Test/Nozzle check แล้วถ่ายรูปผลพิมพ์เก็บไว้ (ถ้าถ่ายได้) ข้อมูลนี้ช่วยให้ประเมินได้แม่น เช่น

1.  สีครบไหม (ดำ/ฟ้า/แดง/เหลืองหรือชุดสีตามรุ่น)
2.  มีเส้นหลุด เส้นแตก หรือสีซีดผิดปกติไหม
3.  มีแถบขาว/ดำซ้ำๆ หรือพื้นที่ไม่ติดหมึกหรือไม่
4.  ขอบภาพคมชัดตามปกติหรือไม่

### 3) เช็คลิสต์ “ความพร้อมอุปกรณ์” ให้ครบ เพื่อให้ราคาดีขึ้น

หลายครั้งราคาจะขึ้นหรือลงตามความครบของอุปกรณ์และสภาพการใช้งาน การเตรียมของให้พร้อมจะช่วยให้กระบวนการตรวจสภาพรวดเร็วขึ้น

*   สายไฟ/อะแดปเตอร์ครบหรือไม่
*   มีสาย USB หรือการเชื่อมต่อที่ใช้งานจริงหรือไม่
*   มีคู่มือ/กล่องเดิม/ใบรับประกัน (ถ้ามี) หรือเอกสารที่เกี่ยวข้อง
*   มีคาร์ทริดจ์/หมึกคงเหลือหรือชุดอุปกรณ์ประกอบที่เกี่ยวข้องหรือไม่

**Checklist แนะนำ (ทำได้ทันที)**

*   ลองเปิดเครื่องและทดสอบการพิมพ์อย่างน้อย 1 ครั้ง
*   จดอาการที่พบ เช่น สีเพี้ยน เส้นแตก หรือขึ้น error code
*   จัดเตรียมสายไฟ/อะแดปเตอร์และอุปกรณ์ที่มีทั้งหมด
*   แจ้งอายุการใช้งานคร่าวๆ และช่วงเวลาที่ใช้งานครั้งล่าสุด

## FAQ เครื่องพิมพ์รูปมือสอง

### 1) ถ้าเครื่องพิมพ์รูปเปิดติดแต่พิมพ์ไม่ออก ได้ไหม?

ได้ครับ/ค่ะ โดยราคาจะประเมินตามสาเหตุและระดับความผิดปกติที่ตรวจได้ เช่น หัวพิมพ์อุดตัน ระบบดึงกระดาษ หรือมี error code

### 2) ถ้าไม่มีอุปกรณ์ครบ (เช่น สายไฟหรือสาย USB) ราคาจะลดมากไหม?

### 3) ต้องถอดหมึก/คาร์ทริดจ์ก่อนนำมาขายหรือไม่?
