## ทำไมต้องขาย CPU มือสองกับ Winner IT ในขอนแก่น

*   ยึดหลักตรวจสภาพก่อนสรุปราคา

## ตรวจสภาพ CPU อะไรบ้างที่มีผลต่อราคา

### 1) ความสมบูรณ์ของขา/หน้าสัมผัส

จุดสำคัญที่สุดคือหน้าสัมผัสและขา CPU หากมีรอยงอ รอยครูด หรือความเสียหายที่ทำให้สัมผัสไม่เต็ม อาจทำให้ใช้งานไม่เสถียรหรือไม่สามารถใช้งานได้จริง ราคาจึงต้องสะท้อนความเสี่ยงที่อาจเกิดขึ้น

### 2) สภาพตัวชิปและความสะอาด

ความสะอาดบนผิวชิปและบริเวณโดยรอบช่วยลดปัญหาความชื้นหรือคราบที่อาจส่งผลต่อการใช้งาน ทั้งยังสะท้อนการดูแลรักษา หากมีคราบสกปรกหนักหรือร่องรอยความเสียหายที่ชัดเจน จะส่งผลต่อการประเมิน

### 3) อาการเคยใช้งานมาก่อน (ถ้าคุณมีข้อมูล)

หาก CPU เคยใช้งานอยู่แล้วและเปลี่ยนเพราะอัปเกรด คุณบอกเราได้เลย เช่น “ใช้งานได้ปกติ” หรือ “มีอาการบูตไม่ขึ้น/ดับเอง” ข้อมูลเหล่านี้ช่วยให้ประเมินความคุ้มค่าได้แม่นขึ้น

### 4) อุปกรณ์ประกอบที่มากับ CPU

บางกรณี CPU จะมีของประกอบที่ช่วยให้ใช้งานต่อได้ง่าย เช่น กล่อง/เอกสาร/สติกเกอร์ หรืออุปกรณ์ที่เกี่ยวข้องที่คุณมีอยู่ การมีของประกอบอาจทำให้ประเมินได้สูงขึ้น เพราะลดภาระในการจัดการต่อ

1.  ตรวจหน้าสัมผัส: ไม่มีงอ/ไม่มีรอยแตก
2.  ตรวจความสะอาด: ไม่มีคราบหนัก/ไม่มีคราบผิดปกติ
3.  เตรียมข้อมูล: รุ่น, สถานะใช้งาน, อุปกรณ์ประกอบที่มี

## วิธีประเมินราคาแบบโปร่งใส: คุณจะรู้ว่าราคาเกิดจากอะไร

### 1) เราเทียบ “รุ่น-เจเนอเรชัน-ความต้องการใช้งาน”

ราคาของ CPU ไม่ได้มาจากแค่ “ยี่ห้อ” แต่ต้องดูรายละเอียด เช่น รุ่นย่อย สเปก และความนิยมในตลาดของพื้นที่และกลุ่มลูกค้าที่ต้องการนำไปใช้ต่อจริง Winner IT จะพิจารณาความต้องการและความเหมาะสมของ CPU ในการใช้งานตามสภาพที่คุณส่งมา

### 2) สภาพใช้งานจริง: ลดความเสี่ยง = ราคาสะท้อนความมั่นใจ

CPU ที่สภาพดี ขา/หน้าสัมผัสสมบูรณ์ และมีประวัติการใช้งานชัดเจน มักถูกประเมินได้ดีกว่า CPU ที่ไม่ทราบสภาพหรือมีรอยเสียหาย การประเมินจึงเป็นการ “ลดความไม่แน่นอน” ให้กับทั้งสองฝ่าย

### 3) เงื่อนไขของของที่ส่งมอบ

การประเมินราคายังรวมถึงความครบของข้อมูลและอุปกรณ์ที่เกี่ยวข้อง เช่น กล่องเดิมหรือเอกสาร (ถ้ามี) ซึ่งช่วยยืนยันรุ่นและทำให้จัดเก็บ/นำไปใช้งานได้สะดวก

### 4) คำอธิบายผลการประเมินที่เข้าใจง่าย

หลังตรวจสอบ เราจะแจ้งข้อเสนอพร้อมเหตุผลหลักที่ทำให้ราคาตามช่วงนั้น เช่น “สภาพหน้าสัมผัสดี”, “มีรอยเล็กน้อย”, “ไม่แน่ใจอาการใช้งาน” เพื่อให้คุณตัดสินใจได้อย่างมีข้อมูล ไม่ใช่รับข้อเสนอแบบผ่านๆ

**คำแนะนำ:** ก่อนติดต่อ ลองเตรียม “รูป/ข้อมูลรุ่น” ให้พร้อม จะช่วยให้ประเมินเร็วขึ้นและลดการตีความผิดพลาด

*   ส่งรูปชัด: หน้าสัมผัส/ขา, ตัวชิป
*   แจ้งรุ่นตามที่พิมพ์บนตัว CPU
*   บอกประวัติการใช้งานล่าสุดแบบตรงไปตรงมา

## เตรียม CPU ให้พร้อมขาย: เช็กลิสต์ก่อนส่งมอบ

### 1) เช็กลิสต์เตรียมก่อนแพ็ก (ทำตามได้เลย)

การแพ็กที่ดีช่วยลดโอกาสเกิดรอยงอระหว่างขนส่ง ซึ่งเป็นเหตุผลสำคัญที่ทำให้ประเมินได้เต็มที่

*   **ถอด CPU อย่างระมัดระวัง** โดยไม่จับเฉพาะหน้าสัมผัส
*   **เช็ดทำความสะอาดแบบเบา** เฉพาะคราบสกปรกที่เห็นได้ (หลีกเลี่ยงการขัดแรง)
*   **ใส่ถุงกันไฟฟ้าสถิต (ESD bag)** ถ้ามี
*   **ใช้กล่อง/วัสดุกันกระแทก** รองทุกด้าน
*   **ติดป้าย** ระบุ “รุ่น CPU” และ “จำนวน”

### 2) รูปที่ควรถ่ายเพื่อให้ประเมินไว

หากคุณถ่ายรูปไว้ก่อนส่ง จะทำให้เราเช็คสภาพเบื้องต้นได้เร็วขึ้น คุณสามารถถ่ายตามนี้

1.  รูปด้านที่เห็น “รุ่น/สเปกที่พิมพ์บนตัว CPU”
2.  รูปหน้าสัมผัส/ขาให้ชัด (มุมตรง ไม่เอียง)
3.  รูปตัวชิปโดยรวม (เห็นรอยแตก/รอยครูดถ้ามี)

### 3) ข้อมูลที่ควรแจ้งให้ครบ

เพื่อให้ราคาเป็นธรรม เราขอข้อมูลหลัก ๆ ที่เกี่ยวกับการใช้งานและสภาพ คุณสามารถจด/พิมพ์มาในแชทได้เลย

*   ยี่ห้อ/รุ่น/เลขสเปก
*   CPU เคยใช้งานมาก่อนไหม (ใช้งานได้ปกติ / มีอาการผิดปกติ)
*   มีอุปกรณ์เดิมหรือกล่องหรือไม่ (ถ้ามี)
*   เหตุผลที่ขาย (เช่น อัปเกรด)

## ขั้นตอนรับซื้อจริง ตั้งแต่ทักแชทจนจบดีล

### 1) ทักแชทพร้อมข้อมูลรุ่นและรูป

เริ่มจากคุณส่งข้อมูล CPU ที่ต้องการขาย ไม่ว่าจะเป็นรุ่น เลขสเปก หรือรูปสภาพจริง เพื่อให้เราตรวจสอบเบื้องต้นได้เร็ว

### 2) แจ้งรายละเอียดการตรวจและเงื่อนไขเบื้องต้น

เพื่อความโปร่งใส เราจะแจ้งว่าหลังจากได้รับของจะประเมินอะไรบ้าง และปัจจัยใดที่ทำให้ราคาสูง/ต่ำ เพื่อให้คุณเตรียมใจและตัดสินใจได้อย่างมั่นใจ

### 3) ประเมินสภาพและสรุปราคา

เมื่อได้รับ CPU ทีมตรวจสภาพจะประเมินตามมาตรฐาน เช่น หน้าสัมผัส ความสมบูรณ์ และความเป็นไปได้ในการใช้งานต่อ จากนั้นจึงสรุปข้อเสนอให้ชัดเจน

### 4) นัดส่งมอบ/รับสินค้า และปิดดีลอย่างเป็นระบบ

การส่งมอบจะทำตามขั้นตอนที่ชัดเจน คุณจะได้รับการยืนยันตามรายละเอียดที่ตกลงกัน เพื่อให้ดีลจบอย่างปลอดภัยและตรวจสอบได้

**เช็คลิสต์ก่อนส่งมอบ:**

*   ยืนยันรุ่นตรงตามที่แจ้ง
*   แพ็กแน่นหนา ลดความเสี่ยงจากขนส่ง
*   ตรวจรูป/ข้อมูลที่ส่งไว้ให้สอดคล้องของจริง
*   เตรียมช่องทางติดต่อที่สะดวก (เพื่อยืนยันขั้นตอน)

## FAQ รับซื้อ CPU มือสอง

### 1) รับซื้อ CPU รุ่นอะไรบ้าง?

โดยทั่วไปเรารับซื้อ CPU ตามรุ่นและสเปกที่มีความต้องการใช้งาน โดยจะประเมินจากข้อมูลรุ่นและสภาพที่คุณส่งมา หากต้องการความชัวร์ ส่งรูปและเลขสเปกเข้ามาก่อน แล้วเราจะตอบช่วงราคาที่เหมาะสม

### 2) ถ้า CPU เคยมีอาการผิดปกติ ยังขายได้ไหม?

ขายได้ในหลายกรณี แต่ราคาจะขึ้นอยู่กับ “สภาพจริง” และความเป็นไปได้ในการใช้งานต่อ คุณสามารถแจ้งอาการที่เคยเกิดขึ้น (เช่น เปิดแล้วไม่ติด/บูตไม่ผ่าน) เพื่อให้เราประเมินได้ตรง

### 3) ต้องมีคูลเลอร์หรืออุปกรณ์ประกอบถึงจะได้ราคาดีไหม?

ไม่จำเป็นเสมอไป แต่การมีอุปกรณ์ประกอบบางประเภทอาจช่วยให้การนำไปใช้งานต่อสะดวกขึ้น และทำให้ประเมินได้ใกล้เคียงกับมูลค่าจริงมากขึ้น หากคุณมี ให้แจ้งและส่งรูปประกอบ

### 4) ทำไมต้องดูหน้าสัมผัส/ขาอย่างละเอียด?

เพราะเป็นจุดที่กระทบต่อการสัมผัสกับเมนบอร์ดโดยตรง หากมีรอยงอหรือเสียหาย การใช้งานอาจไม่เสถียรหรือไม่สามารถใช้งานได้จริง ส่งผลให้ราคาต้องสะท้อนความเสี่ยง

### 5) ส่งของยังไงให้ปลอดภัยและไม่กระทบราคา?

แพ็กใส่ถุงกันไฟฟ้าสถิต (ถ้ามี) จากนั้นใช้กล่องที่มีวัสดุกันกระแทกรองทุกด้าน และยึดชิ้นงานให้ไม่กระแทกกันระหว่างขนส่ง ยิ่งแพ็กดี โอกาสเกิดความเสียหายจากทางส่งจะยิ่งต่ำ

### 6) ใช้เวลาประเมินนานไหม?

ระยะเวลาขึ้นอยู่กับความครบของข้อมูลที่คุณส่งมาและคิวการตรวจสอบ เมื่อได้รูปและข้อมูลรุ่นชัดเจน เราสามารถประเมินเบื้องต้นได้เร็ว และสรุปราคาตามการตรวจสภาพจริงหลังได้รับของ

### 7) การประเมินราคามีความโปร่งใสยังไง?

เราจะยึดหลักสภาพจริงของ CPU เป็นหลัก และแจ้งปัจจัยหลักที่ทำให้ราคาเป็นช่วงนั้น เพื่อให้คุณเข้าใจเหตุผล ไม่ใช่ให้ข้อเสนอแบบคลุมเครือ
