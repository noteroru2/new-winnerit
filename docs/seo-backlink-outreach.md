# Winner IT — แผนสร้าง backlink คุณภาพ

เป้าหมายคือสร้างลิงก์ที่เกี่ยวข้องกับธุรกิจและตรวจสอบได้ ไม่ใช้ sitewide link หรือเครือข่ายเว็บเพื่อดัน anchor text ซ้ำ ๆ

## งานที่ต้องทำก่อน outreach

1. ทำข้อมูล Winner IT, บริษัท อำพล เทรดดิ้ง จำกัด, ที่อยู่, โทรศัพท์, เวลาเปิด และ URL ให้ตรงกันทุกช่องทาง
2. อัปเดต Google Business Profile พร้อมรูปหน้าร้าน ภายในร้าน ทีมงาน และขั้นตอนตรวจเครื่องจริง
3. ใช้หน้า `/รับซื้อคอมพิวเตอร์/` เป็น URL หลักสำหรับการอ้างอิงเรื่อง PC มือสอง
4. สร้างหน้าแหล่งข้อมูลที่คู่ค้ากล้าอ้างอิง เช่น checklist ลบข้อมูลก่อนขาย และคู่มือประเมินสเปก PC

## ลำดับเป้าหมาย

- เว็บไซต์คู่ค้าหรือซัพพลายเออร์ที่มีความสัมพันธ์ทางธุรกิจจริง
- สมาคม/หอการค้า/ไดเรกทอรีธุรกิจในอุบลราชธานีที่มีการตรวจสอบสมาชิก
- สื่อท้องถิ่นหรือสื่อเทคโนโลยีที่รับบทความผู้เชี่ยวชาญโดยมีบรรณาธิการ
- มหาวิทยาลัย บริษัท หรือองค์กรที่มีหน้าโครงการจัดการอุปกรณ์ IT เก่า
- เว็บไซต์รีวิวธุรกิจที่แสดงชื่อ ที่อยู่ และเบอร์โทรตรงกับข้อมูลทางการ

## หลัก anchor text

- เน้นชื่อแบรนด์และ URL: `Winner IT`, `บริษัท อำพล เทรดดิ้ง จำกัด`, `winnerit.in.th`
- ใช้ anchor ตามบริบท เช่น `คู่มือเตรียมคอมพิวเตอร์ก่อนขาย`
- หลีกเลี่ยงการย้ำ exact match เช่น `รับซื้อคอมพิวเตอร์` ในทุกลิงก์

## ข้อความติดต่อฉบับย่อ

> สวัสดีครับ ทีม Winner IT ภายใต้บริษัท อำพล เทรดดิ้ง จำกัด ได้จัดทำ [ชื่อคู่มือ/ข้อมูล] สำหรับผู้ที่ต้องการจัดการอุปกรณ์ IT มือสอง เนื้อหาครอบคลุม [ประโยชน์เฉพาะ] หากเหมาะกับผู้อ่านของคุณ ยินดีให้ใช้เป็นแหล่งอ้างอิงที่ [URL] โดยไม่มีเงื่อนไขเรื่อง anchor text ครับ

## การวัดผลรายเดือน

- จำนวน referring domains ใหม่ที่เกี่ยวข้องและได้รับการตรวจสอบ
- หน้าที่ได้ลิงก์และ query ที่ impressions เพิ่มขึ้นใน Google Search Console
- ลิงก์เสีย/ลิงก์สแปมที่ควรติดตาม โดยไม่รีบ disavow หากยังไม่มีหลักฐานผลกระทบ
- lead ที่มาจาก referral และ organic landing page
